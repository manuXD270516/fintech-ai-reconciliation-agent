# Procedimiento de aprobación humana

Documento sintético de política interna.

## Segregación de funciones

Quien propone una recomendación no puede aprobarla. Sólo un supervisor puede aprobar, rechazar o pedir más información, siempre con motivo escrito y sobre la versión vigente del caso.

## Efecto de aprobar

Aprobar registra una decisión en el expediente. No ejecuta reembolsos, ajustes contables ni movimientos de dinero; esas acciones se realizan fuera del sistema por las áreas responsables.

## Recomendaciones obsoletas

Si llega evidencia nueva o un run más reciente, la recomendación anterior queda obsoleta y la aprobación pendiente se invalida.
